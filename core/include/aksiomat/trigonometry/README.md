# trigonometry

Aktivni javni C++20 ugovori trigonometrijske domene:

- `Angles` — pretvorbe, normalizacija i jedinična kružnica
- `TrigFunctions` — sin, cos, tan, inverzne funkcije i karakteristični kutovi
- `RightTriangle` — potpuno rješavanje pravokutnog trokuta
- `GeneralTriangle` — SSS, SAS i ASA/AAS slučajevi
- `IdentitiesEquations` — temeljni identiteti i intervalne jednadžbe

API je neovisan o obrazovnoj razini; trenutačni web prikaz namijenjen je srednjoj školi.
