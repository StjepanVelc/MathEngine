# analytic_geometry

Aktivni javni C++20 ugovori srednjoškolske Analitičke geometrije:

- `PointsVectors` — vektorska aritmetika, duljina, skalarni produkt, determinanta i kut
- `LinesDistances` — pravci u općem obliku, odnosi, presjeci i udaljenosti
- `Circles` — konstrukcije, opseg/površina i položaj točke
- `Conics` — parabola, elipsa i hiperbola u standardnom položaju

API ostaje neovisan o obrazovnoj razini i web prikazu.
