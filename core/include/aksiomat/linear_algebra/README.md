# linear algebra

Planirani javni C++ ugovori za domenu. Linearna algebra: vektori, matrice, determinante, linearni sustavi i vektorski prostori.

Ova mapa ne pripada jednoj obrazovnoj razini: isti API može koristiti srednjoškolski i napredni frontend s različitim primjerima i objašnjenjima.

Datoteke se dodaju u CMake tek kada postoji stvarna implementacija i testovi.
