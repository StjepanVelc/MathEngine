# sequences

Aktivni javni C++20 ugovori domene nizova i redova:

- `SequenceAnalysis` — diskretne točke, razlike, min/max i monotonost
- `ArithmeticSequence` — opći član, suma, generiranje i traženje indeksa
- `GeometricSequence` — članovi, konačne sume i konvergencija beskonačnog reda
- `Recurrences` — aritmetičke/geometrijske rekurzije i Fibonacci
- `Applications` — kamate, populacija, postotne promjene i amortizacija

API je neovisan o obrazovnoj razini; trenutačni web prikaz namijenjen je srednjoj školi.
