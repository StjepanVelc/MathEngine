# geometry

Aktivni javni C++20 ugovori geometrijske domene:

- `UnitConversion` — duljina, površina, obujam i kapacitet
- `PlaneShapes` — opseg i površina osnovnih ravninskih likova
- `Triangles` — klasifikacija, kutovi i Pitagorin poučak
- `Solids` — oplošje i obujam osnovnih tijela
- `Coordinates` — udaljenost i polovište točaka

API nije vezan uz obrazovnu razinu; osnovnoškolski web sloj samo bira primjere, objašnjenja i prikaz.
